# Contributing to SpendWise AI

Thanks for your interest in improving SpendWise AI!

## Before contributing
- Search existing issues before opening a new one.
- For large features, open an issue first to discuss the approach.
- Keep the app lightweight and dependency-free unless a dependency is justified.

## Pull request checklist
- [ ] The UI works on desktop and mobile.
- [ ] Keyboard navigation and visible focus are preserved.
- [ ] New data is validated before saving.
- [ ] No secrets, API keys, or personal financial data are committed.
- [ ] README documentation is updated if behavior changes.

## Development
Open `index.html` in a browser or use VS Code Live Server. The app is built with plain HTML, CSS, and JavaScript; no build step is needed.
